# Jupyter

Notebooks — mostly for math, geo, and surface analysis.

## Topics

- [`ds/`](ds) — data-science course notebooks (fractions, functions, linear coefficients).
- [`faults/`](faults) — geological fault modeling: `fault3D`, `surface3D`, `plane`, `variogram`. The big one.
- [`gempy/`](gempy) — GemPy 2D/3D visualization and Kriging.
- [`geometry/`](geometry) — small geometry experiments.
- [`math/`](math) — quadratic equations, point-finding helpers.
- [`scanavi/`](scanavi) — Scanavi / fractions practice.
