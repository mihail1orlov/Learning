# ESP8266

Tiny Wi-Fi boards doing tiny things.

## Sketches

- [`TelegramPowerManagement/`](TelegramPowerManagement) — a small lab of `.ino` sketches:
  - `ScanNet.ino` — list nearby Wi-Fi networks.
  - `WebServerHelloEsp.ino` — minimal HTTP server.
  - `WebServerLedControll.ino` — toggle an LED over HTTP.
  - `TelegramBotEcho.ino` — Telegram bot replying with `echo`.
