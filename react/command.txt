# React — first app via Create React App

## Prereq

# Install Node.js, then verify:
node -v
# Quick sanity REPL check:
#   console.log("test string")

## Scaffold the project

# Reference (now archived but still works):
#   https://reactjs.org/docs/create-a-new-react-app.html
npx create-react-app my-app

# CRA reports something like:
#   Success! Created my-app at /Users/mihail_orlov/Documents/repos/my-app
#
#   Inside that directory you can run:
#
#     npm start         Start the dev server.
#     npm run build     Bundle the app into static files for production.
#     npm test          Start the test runner.
#     npm run eject     Remove this tool and copy build deps + scripts
#                       into the app directory. NOTE: this is one-way.

cd my-app
npm start
