# WireGuard server in Docker via Portainer

A short recipe for running a WireGuard VPN server on an Ubuntu host
through Portainer, using the `linuxserver/wireguard` image.

## 1. Confirm your public IP

  curl ifconfig.me

This is the IP your peers will dial out to.

## 2. Pick a non-default UDP port

The WireGuard default is `51820`. Pick something less obvious in the
ephemeral range (`49152–65535`) — call it `yourPort`. Substitute it in
the compose file below.

## 3. Deploy the stack in Portainer

1. Open Portainer.
2. **Stacks → Add Stack** for a new WireGuard stack.
3. Paste the compose snippet at the bottom of this file into the *Web
   editor*.
4. Replace `yourPort` (in `SERVERPORT` and `ports`) with the port
   chosen in step 2.
5. Click **Deploy the Stack**.

## 4. Manage peers

The container exposes a web UI on the address and port you configured.
Use it to add / revoke peers.

## 5. Install and configure a peer

On the device you want to connect:

1. Install the official WireGuard client.
2. Import the peer config:
   - Copy `/home/user/wireguard/config/peer_configs/{peer_name}.conf`
     from the server.
   - Import it in the client app and toggle the connection on.
3. Or scan the QR code:
   - Open `/home/user/wireguard/config/peer_configs/{peer_name}.png`
     in any image viewer on the server.
   - Scan with the WireGuard mobile app — settings are imported
     automatically.

## 6. Verify

  wg show

You should see the peer's public key and recent handshake / transfer
counters. If not, check the server logs in Portainer.

## docker-compose

services:
  wireguard:
    image: linuxserver/wireguard
    container_name: wireguard
    cap_add:
      - NET_ADMIN
      - SYS_MODULE
    environment:
      - PUID=1000
      - PGID=1000
      - TZ=Europe/Kyiv
      - SERVERPORT=yourPort
      - PEERS=25                  # optional
      - PEERDNS=auto              # optional
      - INTERNAL_SUBNET=10.13.13.0 # optional
    volumes:
      - /home/user/wireguard/config:/config
      - /home/user/wireguard/modules:/lib/modules
    ports:
      - yourPort:51820/udp
    restart: unless-stopped
