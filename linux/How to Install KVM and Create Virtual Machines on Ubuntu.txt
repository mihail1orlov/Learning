# KVM on Ubuntu — install and first VM

Ubuntu community guide:
  https://help.ubuntu.com/community/KVM/Installation

## Prerequisite: hardware virtualisation

KVM only works if the CPU exposes hardware virtualisation — Intel VT-x
or AMD-V. To check:

  egrep -c '(svm|vmx)' /proc/cpuinfo

Any number above 0 means support is available.

## Nested virtualisation (running KVM inside Hyper-V)

On the Hyper-V host (PowerShell), with the VM powered OFF, expose
virtualisation extensions to the guest:

  Get-VM
  Set-VMProcessor -VMName <VMName> -ExposeVirtualizationExtensions $true

After that, KVM can run inside the Hyper-V VM.

## Modern install (Ubuntu 18.04+)

The old "How-To Geek" guide
(https://www.howtogeek.com/117635/how-to-install-kvm-and-create-virtual-machines-on-ubuntu/)
is mostly out of date — `libvirt-bin` no longer exists. Use this
instead:

  sudo apt update && sudo apt upgrade
  cat /etc/debian_version

  sudo apt install qemu-kvm libvirt-daemon-system libvirt-clients bridge-utils -y

  sudo systemctl status libvirtd

  # Optional: GUI
  sudo apt install virt-manager

  # Make the default network start automatically at boot
  sudo virsh net-autostart default

  # Add yourself to the libvirt group so you don't need sudo for `virsh`
  sudo adduser $(whoami) libvirt
  groups $(whoami)

## Verify

  sudo ls -la /var/run/libvirt/libvirt-sock
  # Expected ownership:
  #   srw-rw---- 1 root libvirt 0 ... /var/run/libvirt/libvirt-sock

  ls -l /dev/kvm
  # Expected ownership:
  #   crw-rw---- 1 root kvm 10, 232 ... /dev/kvm

## Useful paths

  /var/lib/libvirt/images/         # disk images live here
  /etc/libvirt/qemu/networks/      # virtual network definitions
