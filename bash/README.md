# Bash & Batch

A grab bag of one-off shell snippets — useful enough to remember, too small to live anywhere else.

## Snippets

- [`netstatPort.txt`](netstatPort.txt) — find process owning a port.
- [`reboot.bat`](reboot.bat) — Windows quick-reboot.
- [`update_termsrv.bat`](update_termsrv.bat) — patch `termsrv.dll` for multi-RDP (see also [`../windows/`](../windows)).
- [`mine/getDate.bat`](mine/getDate.bat) — current date as a filename-safe string.
