# Markdown

Examples for everything Markdown can render — Mermaid, PlantUML, KaTeX, tables, embedded HTML.

## Files

- [`markdown.md`](markdown.md) — the main playground (KaTeX math, Mermaid graphs, tables, image embeds, emoji shortcodes).
- [`mermaid-examples.md`](mermaid-examples.md) — flowcharts, sequence, gantt, state, class, pie, journey diagrams.
- [`plantuml-example.md`](plantuml-example.md) — minimal PlantUML sequence diagram.
- [`azure-mermaid-test.md`](azure-mermaid-test.md) — Azure DevOps-flavoured Mermaid syntax.
- [`img/`](img) — images referenced from the examples.
